# YC Early Signal Slack Bot

AI-powered monitoring agent for detecting new Y Combinator and YC Speedrun companies, including early founder announcements on X and LinkedIn.

## Features

- Monitor YC company directory
- Monitor YC Speedrun companies
- Detect early founder announcements
- Monitor X for YC/Speedrun signals
- Monitor LinkedIn for YC/Speedrun signals
- Persistent state to prevent duplicate alerts
- Slack notifications
- Designed for future platform integrations
- Pond agent infrastructure support

## Status

🚧 Initial development

## Goal

Identify YC and Speedrun companies as early as possible so GTM teams can reach founders before competitors.
